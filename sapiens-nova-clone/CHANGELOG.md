# Changelog — клон sapiens-nova.com

Все изменения относительно оригинала сделаны осознанно для статической копии
и подлежат пересмотру в ходе редизайна.

## Что воспроизведено «как есть»
- Вся структура и тексты страниц: главная, программы, детальные страницы программ,
  чекаут, галереи, data privacy terms.
- Визуальная система: цвета (blue #2563eb, azure #aa63eb, navy/stromboli #111827,
  linen #eeffff, sage #f9fafb, cornfield), шрифты (Tobias serif / Karla sans / Mulish),
  радиусы (кнопки 30px/9999px, карточки чекаута 35px, поля 20px), анимации
  (marquee 70s, ken-burns 20s, slideshow 5s, float, accordion).
- Медиа: изображения, видео, иконки, favicon, OG-изображение, шрифты.

## Отличия клона от оригинала (намеренные)
1. **Технологии**: Astro+Tailwind+React+GSAP → чистые HTML/CSS/JS (один файл
   `styles.css`, один `main.js`). Цель — лёгкий доступ к каждому элементу дизайн-системы.
2. **Имена файлов**: ассеты переименованы с хеш-имён (`imperial.Dg19vHxd.js`,
   `fD2g3xK4.webp`) на человекочитаемые (`programme-imperial-hero.jpeg`). Маппинг
   оригинал → клон см. в истории копирования в `content/` (файл links.json — карта ссылок).
3. **Языки**: в оригинале на детальных страницах есть переключатель English /
   繁體中文 / 简体中文 / ไทย (i18n-словари в JS). В клоне — только английская версия.
4. **API**: `/api/programmes`, `/api/validate-promo`, `/api/checkout`, `/api/geo`
   серверные. В клоне данные программ зашиты в `main.js` (PROGRAMMES_DATA),
   промо-код и чекаут — демо (данные никуда не отправляются; на странице чекаута
   показан демо-баннер). Инфо-сессии не регистрируют (кнопки «Registration Closed»).
5. **Галереи**: в оригинале пароль проверяет сервер. В клоне — демо-пароль `SNA2026`
   (в коде `main.js`), контент галереи не скопирован (не публичный).
6. **Регистрация**: на момент копирования закрыта — кнопки «Enroll Now» заменены
   состоянием «Registration Closed» (так делает и оригинал).
7. **Слайд-шоу героя**: оригинал использует GSAP; клон — CSS-transition + JS-таймер
   (5с на слайд, ken-burns-зум на первом слайде). Поведение эквивалентно.
8. **Чекаут**: оригинал создаёт Stripe Checkout Session через POST /api/checkout.
   Клон показывает демо-подтверждение. Поля и валидация формы идентичны.
9. **Мелкие фиксы в клоне**: исправлена валидация поля age (в оригинальном JS
   ветка проверки недостижима), пути к медиа ведут на локальные ассеты.
10. **Meta**: robots noindex на чекауте и галереях (как в оригинале), у остальных
    страниц свои title/description.
